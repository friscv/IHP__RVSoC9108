# RVSoC9108

Linux-capable 32-bit RISC-V SoC for the November 2026 IHP SG13CMOS5L Open Silicon MPW. First tapeout of [Vernii](https://github.com/friscv/vernii) and the [FRISC-V](https://github.com/friscv/friscv) core.

The sources are in [friscv-ihp-sg13cmos5l](https://github.com/friscv/friscv-ihp-sg13cmos5l), tag `v1.0.0`. [RVSoC9108-main](RVSoC9108-main/README.md) says how this release was built and checked.

- `doc/` - datasheet, specification, TRL, `info.json`
- `release/v.1.0.0/` - GDS, CDL, release note
- `RVSoC9108-main/` - constraints, flow config, signoff logs
